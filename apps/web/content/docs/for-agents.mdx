# Canon language reference

Canon v0.3, complete. Every sample here passes `canon check`.

## Text

Files end in .cn. Braces delimit blocks; indent two spaces; one statement per line. Comments are whole lines starting with #. Strings use double quotes. Types and variants are PascalCase; all other names are snake_case. A call's `(` must be on the function name's line.

## Types

Int (53-bit), Float (64-bit), Bool, String, Unit, `List[T]`, `Map[K, V]` (K is Int, Float or String), tuples `(A, B)`, functions `fn(A) -> B`. Built in: `Option[T]` is `Some(value: T) | None`; `Result[T, E]` is `Ok(value: T) | Err(error: E)`; `Error { message: String }`. Generic: `type Box[T] { value: T, }`.

```canon name=types
type Item {
  sku: String,
  qty: Int,
  price: Float,
}

type Step =
  | Call(tool: String)
  | Answer(text: String)
```

## Functions and statements

Parameter and return types are always written; locals never are. Optional clauses, one per line, in order: `effects:` (exactly those used, from fs, io, net, rand, time; none means pure), `requires:`, `ensures:` (`result` is the return value). Contracts must be pure (E103). Generic: `fn id[T](x: T) -> T`.

Statements: `let x = e` (immutable); `var x = e` (mutable); `x = e` or `x.field = e` on a var (field assignment rebinds x to an updated copy); `return e` (always explicit); `if c { } else if c { } else { }`; `for x in xs { }` (Lists only) or `for (i, x) in enumerate(xs) { }` (tuples); `while c { }`; `break` (leaves the innermost loop; there is no continue); a call, or `try` of a call, on its own line. Tests: `test "name" { assert(...) }`; io, time and rand are free in tests, and a test that uses fs or net declares it like a function (`effects: fs` on the line after the name).

```canon include=types
fn restock(items: List[Item], n: Int) -> Float
  effects: io
  requires: n >= 0
  ensures: result >= 0.0
{
  var total = 0.0
  for i in items {
    if i.qty < n {
      print(i.sku)
      total = total + to_float(n - i.qty) * i.price
    }
  }
  return total
}

fn first_short(words: List[String]) -> Int {
  var at = -1
  for (i, w) in enumerate(words) {
    if str_len(w) < 3 && w != "" {
      at = i
      break
    }
  }
  return at
}
```

## Expressions

Precedence, loosest first: `|>` and lambdas; `||`; `&&`; `== != < <= > >=` (never chained); `+ -`; `* / %`; unary `-`, `!` and `try`; calls `f(x)`, fields `a.b`, tuple slots `t.0`.

No methods, no indexing. Literals: `[1, 2]`, `(a, b)`, `P { x: 1, y: 2 }`; there is no unit literal. Lambda bodies are one expression: `|a, b| a + b`; given one n-tuple, an n-parameter lambda unpacks it. `match e { pattern => expr, }` is an expression allowed anywhere: one arm per line, first match wins, exhaustive. Patterns: `_`, a name, a literal, a variant `Some(x)`, a tuple `(a, b)`, nested.

Arithmetic takes two Ints or two Floats; mixing is T009 (use `to_float`). Int division truncates toward zero. `+` also joins two Strings; String with Int is T001 (use `to_string`). `<` etc. take Int, Float or String; `==` is structural on any one type except functions. `&&` and `||` short-circuit. Values are immutable; lambdas capture values.

`x |> f(y)` means `f(x, y)`. Three or more chained calls must be a pipeline, one stage per line; fewer must be nested calls. A call whose first argument is a literal, like `range(0, n)`, can head a pipeline but is never a stage.

`try e` on a Result gives v for `Ok(v)` and returns `Err(x)` early for `Err(x)`; the enclosing function must return a Result with that error type. No `try` in lambdas or tests. A hole `?` or `?name` marks an unknown expression; H001 reports its type and candidate functions.

```canon include=types
fn label(item: Item) -> String {
  return item.sku + (match item.qty {
    0 => " out",
    _ => " in",
  })
}

fn cheapest(items: List[Item]) -> List[String] {
  return items
    |> filter(|i| i.qty > 0)
    |> sort_by(|i| i.price)
    |> map(|i| i.sku)
}
```

## Canonical form

`check` rejects any file `fmt` would change (C001, with the patch). fmt normalizes spacing, parentheses, commas, `else { if }`, comparisons with true or false, `!!`, number literals, `use`, effect and clause order, and pipeline versus nesting, and breaks a statement over 100 characters at its outermost brackets, one item per line. `canon check --fix` applies every mechanical patch (C001, E101, E102, T009) and returns only the rest.

## Running and CLI

`canon run` calls `fn main() -> Unit` (or a main returning a Result; Err prints and exits 1). requires is checked on entry, ensures on every return. In `canon test`, time starts at 0 and moves only by sleep, rand is seeded with 42, and every pure function with a contract is also called on generated inputs; a failing input is reported as `FAIL fuzz name`. A program performs only the effects main declares.

Commands: `canon check [--fix [--write]]`, `fmt [--write]`, `run [--deny fs,net] [--no-contracts]`, `test`; each takes files and `--json`. Exit 0 ok, 1 on diagnostics, failed tests or traps, 2 usage error.

## Standard library

No overloading. Letters are type parameters; K is Int, Float or String; xs is a `List[A]`, m a `Map[K, V]`. Pure unless an effect is shown.

```text
len(xs) -> Int; reverse(xs) -> List[A]; enumerate(xs) -> List[(Int, A)]
map(xs, fn(A) -> B) -> List[B]; filter(xs, fn(A) -> Bool) -> List[A]
fold(xs, init: B, fn(B, A) -> B) -> B
sum(List[Int]) -> Int; sum_float(List[Float]) -> Float
sort_by, sort_desc_by(xs, key: fn(A) -> K) -> List[A]   stable
group_by(xs, key: fn(A) -> K) -> List[(K, List[A])]   first-seen order
```

## Diagnostics

`canon check --json` prints `{ ok, canonical, diagnostics }`; each has code, message, line, col, maybe `data` and `fix.diff` (a unified diff to apply as is).

P001 parse · P002 comment placement · P003 local annotation · P004 non-call statement · P005 stage not a call · C001 not canonical · L001 line over 100 chars that fmt cannot break (split it with let) · N001 naming · M001 `use` other than `std.<name>` · E100 unknown effect · E101 undeclared effect · E102 unused effect · E103 effect in a contract · H001 hole · T001 type mismatch · T002 unknown name · T003 argument count · T004 non-exhaustive match · T005 missing return · T006 assigning a non-var · T007 misplaced try · T008 unknown field · T009 Int and Float mixed · T010 break outside a loop. C001, E101, E102, T004 and T009 carry patches; a T001 may list candidate patches in `data.suggestions`.

Traps print one JSON object (code, message, line, col, stack): R001 requires failed · R002 ensures failed · R003 Int overflow · R004 division by zero · R005 assert failed · R006 effect denied by host
