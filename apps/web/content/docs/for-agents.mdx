# Canon language reference

Canon v0.4, complete. Every sample here passes `canon check`.

## Text

Files end in .cn. Braces delimit blocks; indent two spaces; one statement per line. Comments are whole lines starting with #. Strings use double quotes. Types and variants are PascalCase; all other names are snake_case. A call's `(` must be on the function name's line.

## Types

Int (53-bit), Float (64-bit), Bool, String, Unit, `List[T]`, `Map[K, V]` (K is Int, Float or String), tuples `(A, B)`, functions `fn(A) -> B` (pure) or `fn(A) -> B effects: io` (calling it performs io). Built in: `Option[T]` is `Some(value: T) | None`; `Result[T, E]` is `Ok(value: T) | Err(error: E)`; `Error { message: String }`. Generic: `type Box[T] { value: T, }`.

```canon name=types
type Item {
  sku: String,
  qty: Int,
  price: Float,
}

type Step =
  | Call(tool: String)
  | Answer(text: String)
```

## Functions and effects

Parameter and return types are always written; locals never are. Optional clauses, one per line, in order: `effects:` (exactly those used, from fs, io, net, rand, time; none means pure), `requires:`, `ensures:` (`result` is the return value). Contracts must be pure (E103). Generic: `fn id[T](x: T) -> T`. Calling, naming or using in a lambda an effectful function uses its effect.

Calling a function value performs its type's effects, so the caller declares them; passing an effectful function where the function type is pure is T011 (so `map(xs, print)` is T011: use a `for` loop). Every signature bounds what its function can do, and a program performs only the effects its entry point declares (checked, and enforced at run time).

## Statements

`let x = e` (immutable); `var x = e` (mutable); `x = e` or `x.field = e` on a var (field assignment rebinds x to an updated copy); `return e` (always explicit); `if c { } else if c { } else { }`; `for x in xs { }` (Lists only); `for (i, x) in enumerate(xs) { }` (names each tuple slot; `_` skips one); `while c { }`; `break` alone on its line leaves the innermost loop (no continue); a call, or `try` of a call, on its own line.

Tests: `test "name" { assert(...) }`. io, time and rand are free in tests (virtual clock and seed); a test using fs or net declares it with `effects: fs` on the line after its name.

```canon include=types
fn restock(items: List[Item], n: Int) -> Float
  effects: io
  requires: n >= 0
  ensures: result >= 0.0
{
  var total = 0.0
  for i in items {
    if i.qty < n {
      print(i.sku)
      total = total + to_float(n - i.qty) * i.price
    }
  }
  return total
}

fn first_short(words: List[String]) -> Int {
  var at = -1
  for (i, w) in enumerate(words) {
    if str_len(w) < 3 && w != "" {
      at = i
      break
    }
  }
  return at
}

test "first short" {
  assert(first_short(["canon", "", "is"]) == 2)
}
```

## Expressions

Precedence, loosest first: `|>` and lambdas; `||`; `&&`; `== != < <= > >=` (never chained); `+ -`; `* / %`; unary `-`, `!` and `try`; calls `f(x)`, fields `a.b`, tuple slots `t.0`. So `!(a == b)` needs its parentheses.

No methods, no indexing. Literals: `[1, 2]`, `(a, b)`, `P { x: 1, y: 2 }`; no unit literal. Lambda bodies are one expression: `|a, b| a + b`; an n-parameter lambda given one n-tuple unpacks it. `match e { pattern => expr, }` is an expression allowed anywhere: one arm per line, first match wins, exhaustive. Patterns: `_`, a name, a literal, a variant `Some(x)`, a tuple `(a, b)`, nested.

Arithmetic takes two Ints or two Floats; mixing is T009 (use `to_float`). Int division truncates toward zero. `+` also joins two Strings; String with Int is T001 (use `to_string`). `<` etc. take Int, Float or String; `==` is structural on any one type except functions. `&&` and `||` short-circuit. Values are immutable; lambdas capture values.

`x |> f(y)` means `f(x, y)`. Three or more chained calls must be a pipeline, one stage per line; fewer must be nested calls. A call whose first argument is a literal, like `range(0, n)`, can head a pipeline but is never a stage.

`try e` on a Result gives v for `Ok(v)` and returns `Err(x)` early for `Err(x)`; the enclosing function must return a Result with that error type. No `try` in lambdas or tests. A hole `?` or `?name` marks an unknown expression; H001 reports its type and candidate functions.

```canon include=types
fn label(item: Item) -> String {
  return item.sku + (match item.qty {
    0 => " out",
    _ => " in",
  })
}

fn cheapest(items: List[Item]) -> List[String] {
  return items
    |> filter(|i| i.qty > 0 && i.price > 0.0)
    |> sort_by(|i| i.price)
    |> map(|i| i.sku)
}
```

## Canonical form and the fix loop

`check` rejects any file `fmt` would change (C001, with the patch). fmt fixes spacing, parentheses, commas, `else { if }`, `== true`/`== false`, `!!`, numbers, `use`, effect and clause order, pipeline versus nesting, and old spellings (`and`/`or`/`not`, `set`); it breaks a statement over 100 characters at its outermost list, tuple, record or call brackets, one item per line with trailing commas, and a long `requires`/`ensures` before each `&&` or `||`.

Run `canon check --fix --write --json FILE`. It applies every C001, E101, E102 and T009 patch until none is left and returns only what needs you. T001 may list candidate patches in `data.suggestions` (`to_string(e)`, `unwrap_or(e, ?)`, `Some(e)`, ...): apply the one you mean. T004's patch adds missing arms as holes; apply it, then fill them. Repeat until `"ok": true`.

## Running and CLI

`canon run` calls `fn main() -> Unit` (or a main returning a Result; Err prints and exits 1). requires is checked on entry, ensures on every return. `canon test` runs test blocks, then calls each pure, non-generic function with a contract on 200 seeded generated inputs; a failure prints `FAIL fuzz name: a = -19, b = 12` and the trap.

Commands: `canon check [--fix [--write]]`, `fmt [--write]`, `run [--deny fs,net] [--no-contracts]`, `test`, `build [-o OUT] [--module]`; each takes files and `--json`; `--watch` reruns on save. Exit 0 ok, 1 on diagnostics, failed tests or traps, 2 usage error.

## Standard library

No overloading. Letters are type parameters; K is Int, Float or String; xs is a `List[A]`, m a `Map[K, V]`. Pure unless an effect is shown.
