Canon is the programming language for AI agents. It is typed, compiled, and small enough to fit in a single prompt. Every compiler error ships with its fix.

<HeroTerminal />

Above, `main` prints without declaring it. The compiler returns a stable code (E101) and a patch, a unified diff the agent applies as is. Then the file runs:

```canon
fn main() -> Unit
  effects: io
{
  print("hello, canon")
}
```

## Who it is for

- **Agents write it.** The whole reference fits on one page in the agent's prompt. The compiler answers in JSON, so the agent fixes its own mistakes.
- **People read it.** Canon looks like clean TypeScript or Python. Every function lists its types and its side effects, such as printing or reading files, so a reviewer sees what code can do from its first line.
- **Reviewers diff it.** The formatter turns any spacing or layout of a program into one standard text, so diffs between two versions show only real changes.

Canon compiles to JavaScript and runs in Node and in the browser [playground](/play).
