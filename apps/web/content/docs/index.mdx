Canon is a programming language for AI agents. It is typed, compiled to JavaScript, and small enough that its whole reference fits in a single prompt. Every compiler error has a stable code, and every error with a mechanical fix comes with that fix as a patch.

<HeroTerminal />

Above, `main` prints without declaring that it does. The compiler answers with a stable code (E101) and a patch, a unified diff the agent applies as is. Then the file runs:

```canon
fn main() -> Unit
  effects: io
{
  print("hello, canon")
}
```

## Who it is for

- **Agents write it.** The [Agent reference](/docs/for-agents) is the whole language on one page. `canon check --fix` applies every mechanical patch itself (layout, effect lists, Int and Float conversions), so the agent only sees the problems that need its judgment, answered in JSON.
- **People read it.** Every function states its types and its side effects (printing, files, network, time, randomness). A checked program can perform only the effects its entry point declares, and the runtime enforces that too.
- **Reviewers diff it.** The formatter turns any layout of a program into one standard text, so a diff between two versions shows only real changes.

```canon
fn first_short(words: List[String]) -> Int {
  for (i, w) in enumerate(words) {
    if str_len(w) < 3 && w != "" {
      return i
    }
  }
  return -1
}

test "first short word" {
  assert(first_short(["canon", "is", "small"]) == 1)
}
```

Canon runs in Node and in the browser [playground](/play). The current language is v0.3; [Design notes](/docs/design-notes) say what changed and why, and [Research](/research) shows what has been measured so far.
