# Generated code

Generated code has two jobs: behave exactly like the Canon it came from, and read as if a careful person wrote it. Every file below is the real output for the [quickstart](/docs/fullstack/quickstart)'s `canon/todos.cn`, which tests compare with byte for byte.

## Layout

```text
backend/
  main.py                 written once if missing; yours to edit
  canon_generated/
    models.py             Pydantic v2 models
    logic.py              one plain function per Canon function (one module per Canon module in a larger project)
    api.py                one FastAPI route per api fn
    store.py              SQLite tables
    runtime.py            Result, traps, the HTTP mapping, and helpers where Python differs from Canon
    net.py, accounts.py   only when a project uses hosts, or uuid and passwords
frontend/src/canon/
  types.ts                the wire types
  validate.ts             one validator per api fn with a requires
  client.ts               createClient(baseUrl)
  runtime.ts              Result, request, and the shared helpers
```

The Python depends only on FastAPI, Pydantic and the standard library, and the TypeScript has no dependencies. Generated Python passes `ruff format --check`, `ruff check` and `mypy --strict`. Generated TypeScript passes `prettier --check`, `tsc --strict` and eslint.

```python
from typing import Literal

from pydantic import BaseModel

from .runtime import SafeInt


class Todo(BaseModel):
    id: SafeInt
    title: str
    done: bool


class NewTodo(BaseModel):
    title: str

    kind: Literal["NotFound"] = "NotFound"
```

Every effect becomes a parameter: `create_todo` can touch the `todos` table because it is handed that table, and nothing else.

```python
# Generated by Canon 0.5.0 from canon/todos.cn. Do not edit: change the Canon source.
# canon-hash: sha256:633b2185a32d99f7
from .models import NewTodo, NotFound, Todo, TodoError
from .runtime import Err, Ok, Result, Table, trim


def create_todo(input: NewTodo, todos: Table[Todo]) -> Todo:
    todo = Todo(id=todos.next_id(), title=trim(input.title), done=False)
    todos.insert(todo)
    return todo


def complete_todo(id: int, todos: Table[Todo]) -> Result[Todo, TodoError]:
    match todos.get(id):
        case Todo() as t:
            return Ok(todos.save(Todo(id=t.id, title=t.title, done=True)))
        case None:
            return Err(NotFound(id=id))


def list_todos(page: int, per_page: int, todos: Table[Todo]) -> list[Todo]:
    rows = sorted(todos.scan(), key=lambda t: t.id)
    start = (page - 1) * per_page
    return rows[start : start + per_page]
```

```python
# Generated by Canon 0.5.0 from canon/todos.cn. Do not edit: change the Canon source.
# canon-hash: sha256:7d0d00fb142f1cf1
from typing import Annotated

from fastapi import APIRouter, Depends

from . import logic
from .models import NewTodo, Todo
from .runtime import Table, require, respond, table, trim

router = APIRouter()

Todos = Annotated[Table[Todo], Depends(table("todos", Todo))]


@router.post("/todos")
def create_todo(input: NewTodo, todos: Todos) -> Todo:
    require(len(trim(input.title)) > 0, "str_len(trim(input.title)) > 0")
    return logic.create_todo(input, todos)


@router.post("/todos/{id}/complete")
def complete_todo(id: int, todos: Todos) -> Todo:
    return respond(logic.complete_todo(id, todos))


@router.get("/todos")
def list_todos(page: int, per_page: int, todos: Todos) -> list[Todo]:
    require(
        page >= 1 and per_page >= 1 and per_page <= 100,
        "page >= 1 && per_page >= 1 && per_page <= 100",
    )
    return logic.list_todos(page, per_page, todos)
```

```ts
// Generated by Canon 0.5.0 from canon/todos.cn. Do not edit: change the Canon source.
// canon-hash: sha256:c2546406d8d0a5fe
import { request, type Result, type TransportError, type ValidationError } from "./runtime";
import type { NewTodo, Todo, TodoError } from "./types";
import { validateCreateTodo, validateListTodos } from "./validate";

export function createClient(baseUrl: string) {
  return {
    async createTodo(input: NewTodo): Promise<Result<Todo, ValidationError | TransportError>> {
      const invalid = validateCreateTodo(input);
      if (invalid) return { ok: false, error: invalid };
      return request(baseUrl, "POST", "/todos", { body: input });
    },

    async completeTodo(id: number): Promise<Result<Todo, TodoError | TransportError>> {
      return request(baseUrl, "POST", `/todos/${id}/complete`);
    },

    async listTodos(
      page: number,
      perPage: number,
    ): Promise<Result<Todo[], ValidationError | TransportError>> {
      const invalid = validateListTodos(page, perPage);
      if (invalid) return { ok: false, error: invalid };
      return request(baseUrl, "GET", "/todos", { query: { page, per_page: perPage } });
    },
  };
}
```

## The wire format

| Canon | JSON | Python | TypeScript |
| --- | --- | --- | --- |
| Int | number within ±(2^53 − 1) | SafeInt | number |
| Float | number | float | number |
| Bool, String | boolean, string | bool, str | boolean, string |
| Unit | null | None | null |
| Option[T] | value or null | T \| None | T \| null |
| List[T] | array | list[T] | T[] |
| (A, B) | two-element array | tuple[A, B] | [A, B] |
| Map[String, V] | object | dict[str, V] | Record&lt;string, V&gt; |
| record | object | Pydantic BaseModel | interface |
| sum type | object with a kind field, plus the variant's fields | one model per variant, joined by a union on kind | union of object types on kind |

## Naming

- Field names are identical in Canon, JSON, Python and TypeScript, with no case conversion on the wire, because conversion is where mismatch bugs come from.
- Function and parameter names follow each language: `create_todo` in Python, `createTodo` in TypeScript. Query keys keep the Canon spelling (`per_page`).
- A Canon name that is a Python keyword, or a builtin the generated code relies on, gets a trailing underscore.

## Semantics that differ between the languages

Where Python or TypeScript means something else by the same operator, the generated code calls a helper:
- Int `/` truncates toward zero (`div`).
- `%` takes the dividend's sign (`rem`).
- `str_len` counts code points (`strLen` in TypeScript).
- `trim` removes one shared set of whitespace characters (`trim` on both sides).
- `take` and `drop` never count from the end.

A parity suite evaluates random validation rules in the Canon runtime, the generated Python and the generated TypeScript, and requires identical results. In the generated Python, an Int that leaves the 53-bit range fails when it reaches a record, a table or a response, rather than at the operation.

The Python target cannot yet express a few things, and reports them as G002, naming the function:
- an Option of an Option;
- `to_string` of anything but Int, Float, String and Bool;
- console and file input or output;
- a computed URL in a function that declares several hosts.

## Read-only output

Every generated file starts with a header naming its Canon source and a hash of its contents. Editing one by hand is G001 in `canon check`, which names the Canon source to change instead, and `canon build` refuses to overwrite it unless given `--force`. `main.py` and your UI code are never touched once they exist.
