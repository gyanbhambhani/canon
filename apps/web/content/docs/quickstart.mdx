This page takes you from nothing to a running Canon program, a compiler error, and its fix. You need Node 20 or later. Save this as `hello.cn`:

```canon
fn main() -> Unit
  effects: io
{
  print("hello, canon")
}
```

Run it with npx. Nothing to install first:

```bash
npx canon-lang run hello.cn
```

```text
hello, canon
```

## Install the canon command

The npm package `canon-lang` provides the `canon` command. Install it once:

```bash
npm i -g canon-lang
canon --version
```

The rest of these docs write `canon`. Without the global install, write `npx canon-lang` instead.

## See an error and its fix

Every function lists the side effects it has, such as `io` for printing. Delete the `effects: io` line, so the file reads:

```canon
# expect: E101
fn main() -> Unit {
  print("hello, canon")
}
```

(In these docs, a `# expect: CODE` line marks an example that must fail with that code. It is not part of your file.)

Check it:

```bash
canon check hello.cn
```

```text
hello.cn:1:4: error E101: fn main uses effects it does not declare: io (via print)
  --- a/hello.cn
  +++ b/hello.cn
  @@ -1,3 +1,5 @@
  -fn main() -> Unit {
  +fn main() -> Unit
  +  effects: io
  +{
     print("hello, canon")
   }
hello.cn: 1 problem
```

The error has a stable code (E101), a position (line 1, column 4) and a patch: a unified diff that fixes it. The exit status is 1.

## Apply the fix and run again

Make the edit the patch describes, or let a tool apply it. `--json` puts the patch in `fix.diff`, which `patch -p1` applies as is:

```bash
canon check --json hello.cn | jq -r '.diagnostics[0].fix.diff' | patch -p1
canon check hello.cn
canon run hello.cn
```

```text
patching file hello.cn
hello.cn: ok
hello, canon
```

An agent runs this same loop: check, apply every patch, check again. [Use Canon with your agent](/docs/agents) sets it up.

## Formatting and tests

Canon accepts one layout per program. The formatter turns any spacing or layout into that one standard text, and `check` rejects any other (code C001, with a patch). Save this as `double.cn`:

```canon
# expect: C001
fn double(n:Int)->Int{return (n*2)}

test "double" {
  assert(double(21) == 42)
}
```

`canon fmt --write double.cn` rewrites it, and `canon test double.cn` runs its `test` blocks:

```canon
fn double(n: Int) -> Int {
  return n * 2
}

test "double" {
  assert(double(21) == 42)
}
```

```text
PASS double
1 passed, 0 failed
```

## Build from source

To work on Canon itself, clone the repository. You need pnpm.

```bash
git clone https://github.com/gyanbhambhani/canon
cd canon
pnpm install
pnpm build
node packages/cli/dist/index.js run examples/hello.cn
```

The `examples/` folder holds small programs that each pass `check` and run.
