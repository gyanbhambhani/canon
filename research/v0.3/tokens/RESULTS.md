## Caveats

- Qwen2.5-Coder BPE is a proxy. It merges `{\n`, `:\n`, `,\n` and ` and`/` &&` into single tokens, which is why `:` vs `{`, trailing commas and word operators measure ~0; another tokenizer may differ by a token here and there.
- Python is one hand-written program per task by the analyst, not model output; it is idiomatic (comprehensions, slicing, `str.count`, `re.fullmatch`) and has no comments, docstrings or helpers. Model-written Python would likely be longer. Treat it as a lower bound for a typed mainstream language.
- Python pays for its declarations: dataclasses for records/variants and an `Ok`/`Err` Result (Canon has Result built in; TS got the Result type in its prompt).
- Attribution figures are textual ablations on whole programs; categories overlap and the hypothetical rewrites are approximate (e.g. (e) only strips a `return` that is the last top-level statement; (b) only fires on bodies with one top-level statement).
- The large residual in section 3 is semantic, not syntactic: no indexing/slicing/methods, missing stdlib (character tests, regex, string repeat/count), 53-bit Int caution (GPT wrote bignum Collatz), more helper functions, and hand-rolled integer validation.
