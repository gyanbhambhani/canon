# v0.4 surprisal: the implemented Canon-Py against Canon brace syntax, typed Python and TypeScript

Generated by `analyze.py` from `results/<model>.json` (written by `score.py` over `corpus.json`, built by `corpus.py`). Surprisal is −Σ ln p over a program's tokens (nats) under a local **base** model, conditioned on a prefix that is not scored. Mean per program over the 50 benchmark tasks; brackets are 95% bootstrap intervals over tasks (10,000 resamples, seed 2026). Per token, per character and per node are ratios of sums.

Canon programs are the modal final programs of the v0.2 benchmark (all pass the hidden tests). **Canon-Py rows are those same programs converted by `canon fmt --syntax py`**, so Canon brace vs Canon-Py is a like-for-like comparison of the surface. Typed Python is hand-written and idiomatic (different algorithms, Python's library), so Canon-Py vs Python mixes surface with library and style. Node counts: see the note at the top of `analyze.py` (Canon and Python roughly comparable; TypeScript counts every identifier and keyword, so its per-node figure is low).
